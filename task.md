Создайте одностраничный сайт, используя  Bootstrap 5. На сайте должны быть обязательно следующие элементы Bootstrap:

- Контейнеры, сетки (разметка)
- Заголовки
- Карточки (заполнители)
- Аккордеоны (разворачиваемые панели)
- Формы (типы элементов - любые)
- Таблицы
- Иконки Bootstrap
- Навигационная панель
- Пагинация (нумерация страниц)
- Слайдер (Карусель). Требования: не должен быть огромным и занимать больше 50% экрана, имеет средства навигации (возможность ручного пролистывания слайдов), слайды сопровождаются дополнительными текстовыми блоками с информацией. 

Тематика сайта: Сайт книжного магазина.

Общие требования:

- Сайт в виде лендинга, на котором присутствуют не менее 5х разделов. Штраф  - 5 баллов (за каждый раздел).
- Сайт должен быть адаптивным. Штраф за отсутствие адаптивности  - 10 баллов.
- Сайт должен содержать все заявленные выше компоненты Bootstrap. Штраф за отсутствие отдельного компонента  - 5 баллов. 
- Сайт должен соответствовать тематике варианта (картинки, текст). Шраф -  5 баллов.
- Разделы сайта должны быть оформлены в одинаковом стиле. Шраф - 5 баллов.
